# Capgemini Insurance Website

A professional insurance website showcasing three insurance products: Auto, Health, and Home Insurance.

## Features

- Responsive design with dark and bright color scheme
- Three insurance types with dedicated pages
- Genesys messenger integration for customer support
- Professional UI with smooth animations and hover effects
- Mobile-friendly layout

## Project Structure

```
docs/
├── index.html (main page - insurance.html)
├── auto.html
├── health.html
├── home.html
├── genesys-messenger.js
└── images/
    ├── Auto.png
    ├── Health.png
    ├── Home.png
    └── capgemini.png
```

## Pages

1. **Main Page** (`index.html`) - Displays all three insurance options with clickable cards
2. **Auto Insurance** (`auto.html`) - Auto insurance details and benefits
3. **Health Insurance** (`health.html`) - Health insurance coverage information
4. **Home Insurance** (`home.html`) - Home insurance protection details

## Deployment

This project is deployed using GitHub Pages from the `main` branch, `docs` folder.

Visit the live site at: `https://Mallikvedula.github.io/webpage`

## Contact

For support, use the Genesys messenger available on all pages.
